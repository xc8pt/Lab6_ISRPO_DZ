## Что мы изучали?

### Блочные и строчные теги в HTML. Теги div и span
В HTML все элементы делятся на блочные и строчные.

Блочные теги (div, p, h1 и др.):
- занимают всю доступную ширину страницы;
- всегда начинаются с новой строки;
- могут содержать внутри другие теги.

Строчные теги (span, a, strong и др.):
- занимают только необходимую ширину;
- не переносят строку;
- используются для выделения части текста.

### Теги форматирования текста
- <b> — жирный текст (визуально);
- <strong> — логическое выделение важного текста;
- <i> — курсив (визуально);
- <em> — логическое выделение (курсив);
- <s> — зачёркнутый текст;
- <u> — подчёркнутый текст;
- <sub> — нижний индекс;
- <sup> — верхний индекс;
- <small> — уменьшенный текст;
- <mark> — выделение маркером;
- <br> — перенос строки;
- <hr> — горизонтальная линия;
- <code> — отображение кода.

### Абсолютные и относительные ссылки в HTML. Якорные ссылки. mailto, tel, download
1. Относительные ссылки - ведут на файлы внутри проекта (например, info.html,
media.html);
2. Абсолютные ссылки - ведут на внешние ресурсы (например, сайты в
интернете);
3. Якорные ссылки - позволяют перейти к определённому месту страницы;
- mailto: - открывает почтовый клиент для отправки письма;
- tel: - позволяет позвонить с мобильного устройства;
- download - используется для скачивания файлов.

### HTML изображения. Относительные и абсолютные пути
Изображения в HTML добавляются с помощью тега `<img>`.
- Относительный путь - путь к файлу внутри проекта;
- Абсолютный путь - полный URL к изображению в интернете

### Цитаты в HTML — теги blockquote, cite. Атрибут cite. Источник цитаты в HTML
- `<blockquote>` — используется для длинных цитат, оформляется как отдельный
блок;
- `<cite>` — указывает источник цитаты (книга, автор, сайт);
- атрибут cite — содержит ссылку на источник, но визуально не отображается.

### Медиаконтент в HTML — видео, аудио, фреймы. Теги video, audio, iframe. Тег source 
- `<video>` — добавление видео;
- `<audio>` — добавление аудио;
- `<iframe>` — встраивание внешнего контента (YouTube, карты и т.д.);
- `<source>` — указывает источники медиафайлов.

### Каждый тег имеет свое логическое назначение:
- `<header>` — для вводного заголовка всей страницы.
- `<nav>` — для навигационного меню с ссылками на разделы (#gen2) и другие страницы (media.html, forms.html).
- `<main>` — основной контент страницы, включающий информационные разделы
(`<section>`) и боковые панели (`<aside>`).
- `<section>` — логический раздел с уникальным id.
- `<aside>` — боковая панель для дополнительной, связанной информации (в данном случае — изображения поколений ЭВМ).
- `<footer>` — подвал страницы с информацией о работе.

**Лайфхак**: для быстрого добавления через Emmet можно использовать следующий
вариант:
`header^nav^main>section#gen1+aside+section#gen2+aside^footer`

### Введение в CSS
**Что такое CSS?** CSS (Cascading Style Sheets) — это язык стилей, который
описывает, как HTML-элементы должны отображаться на экране. Он позволяет
управлять цветами, шрифтами, отступами, расположением блоков и многим другим,
полностью преобразуя внешний вид страницы.
**Что означает “Cascading” (Каскадность)?**
CSS применяет стили по приоритету. Если одному элементу задано несколько
стилей, применяется самый специфичный.

### Подключение стилей
В блок `<head>` файла index.html 
```HTML
<head>
    <meta charset=" UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Лабораторная работа №6 - Домашнее задание</title>
<link rel="stylecheet" href="style.css" />
</head>
```
---
**Почему стили в `<head>`?**
Тег `<link>` обязательно должен быть в блоке `<head>`, потому что:
1. Браузер загружает стили **ДО** отображения страницы
- Если стили в `<body>`, страница сначала отобразится без стилей, потом
“прыгнет”
- Это называется FOUC (Flash Of Unstyled Content) — плохая практика
2. `<head>` — место для метаданных
- Кодировка (`<meta charset="UTF-8">`)
- Заголовок (`<title>`)
- Стили (`<link>` или `<style>`)
- Скрипты (иногда)
**Важно:** Атрибут href должен содержать правильный путь к файлу CSS.
**Структура CSS-правила:**
```CSS
селектор{
    свойство1: значение;
    свойство2: значение;
}
```
